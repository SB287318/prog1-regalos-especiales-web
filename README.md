# Regalos Especiales — Programación 1

Obligatorio de **Programación 1** (Universidad ORT): sitio web de experiencias y regalos hecho con **HTML, CSS y JavaScript** puro, sin librerías. Permite explorar experiencias por categoría, cantidad de personas y orden de precio, y realizar compras.

## Estructura

```
index.html
css/estilos.css
js/clases.js       Modelo (clase Sistema y entidades)
js/funciones.js    Lógica de la interfaz
img/
```

## Cómo usarlo

Abrí `index.html` en el navegador. No necesita instalación ni servidor.
